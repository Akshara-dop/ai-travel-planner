# AI Travel Planner ✈️

## About the Project

AI Travel Planner is a web application that uses
artificial intelligence to generate personalized
travel itineraries based on user preferences.

Users can enter their destination, travel duration,
budget, travel type, and preferred activities to
receive a customized travel plan.

## Features

- AI-powered travel itinerary generation
- Destination selection
- Travel duration and budget preferences
- Travel type selection
- Personalized activity suggestions
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- Google Gemini API
- Vercel

## Installation and Setup

1. Clone this repository.
2. Install the project dependencies.
3. Configure your Gemini API key using
   an environment variable.
4. Run the project locally or deploy it
   using Vercel.

## Environment Variables

Configure the required environment variable
in your local `.env` file or deployment settings.

Never publish your API key.
